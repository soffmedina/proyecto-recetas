# GESTOR DE RECETAS DE COCINA

Este proyecto es una aplicacion de escritorio desarrollada en Python que permite gestionar recetas de cocina, ingredientes y categorias. Utiliza una base de datos MySQL para almacenar la informacion y una interfaz grafica con Tkinter.
---
## 🤖 Tecnologias Utilizadas

- **Python 3.11**
- **MySQL** -> con al menos tres tablas relacionadas.
- **Tkinter** -> para la interfaz gráfica.
- **Entorno virtual** -> con "venv"
- **mysql-connector-python** -> para la conexion con la base de datos
